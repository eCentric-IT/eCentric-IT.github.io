01

Definir os Eventos

Notificações assíncronas do recurso

Eventos são notificações assíncronas identificadas por um inteiro único na faixa reservada ao recurso. Declare-os em ecentric.sdk.pas.

ℹ️
Nota: Cada recurso ocupa uma faixa contínua de 100 IDs. Processos usam 200–299, plugins 300–399. Escolha a próxima faixa livre para o seu recurso.
Pascal — SDK 
{ Foo range (400..499): foo lifecycle events
} EVT_FOO_READY     = 400;  { Foo is ready — no payload }
  EVT_FOO_DATA      = 401;  { Data received — payload is UTF-8 text }
  EVT_FOO_TERMINATE = 402;  { Foo terminated — payload is exit code decimal }

Interface e Classe no SDK

Callbacks tipados, IECFoo e TECFoo

2.1 — Callbacks tipados

Pascal — SDK Callbacks 
{ Callback for data received from a Foo object
} TECOnFooData = Procedure(Const ASender: IECFoo; Const AData: String) Of Object;

{ Callback for Foo termination
} TECOnFooTerminate = Procedure(Const ASender: IECFoo; Const ACode: Integer) Of Object;

2.2 — Interface pública

Herda de IECObject. Expõe apenas o que o desenvolvedor precisa ver.

Pascal — SDK Interface 
{ Typed contract for a Foo resource
} IECFoo = Interface(IECObject)
    ['{GUID-ÚNICO-GERADO-AQUI}']
    Function DoSomething(Const AParam: String): Boolean;
    Procedure SetOnData(Const ACallback: TECOnFooData);
    Function GetOnData: TECOnFooData;
    Procedure SetOnTerminate(Const ACallback: TECOnFooTerminate);
    Function GetOnTerminate: TECOnFooTerminate;
    Property OnData: TECOnFooData Read GetOnData Write SetOnData;
    Property OnTerminate: TECOnFooTerminate Read GetOnTerminate Write SetOnTerminate;
  End;

2.3 — Classe de implementação

Pascal — SDK Class 
{ Typed wrapper for a native Foo resource
} TECFoo = Class(TECObject, IECFoo)
  Strict Private
    FOnData: TECOnFooData;
    FOnTerminate: TECOnFooTerminate;

03

Constantes de Protocolo

Identificadores opacos da ABI — prefixo _EC_FOO_*

Identificadores opacos da ABI — prefixo _EC_FOO_*. Nunca expostos na interface pública.

Constante Valor ABI Handle Descrição
_EC_ROOT_FOO 'Root.Foo' 0 Factory — cria nova instância
_EC_FOO_DO 'Foo.DoSomething' N Operação na instância
_EC_FOO_CLOSE 'Foo.Close' N Fecha e libera a instância
Pascal — SDK Constants 
{ Foo
} _EC_ROOT_FOO  = 'Root.Foo';        { factory — handle = 0 }
  _EC_FOO_DO    = 'Foo.DoSomething';
  _EC_FOO_CLOSE = 'Foo.Close';
04

Implementar DoEvent e Métodos

DoEvent, métodos de operação e late binding

4.1 — DoEvent — roteamento de eventos

⚠️
Atenção: Use sempre SetString(LRaw, PAnsiChar(AData), ASize) com tamanho explícito — nunca assuma terminação por nulo. Payload texto é sempre UTF-8. Try..Except vazio em volta do callback: nunca propague exceções do consumidor. Else Inherited delega eventos desconhecidos para a base.
Pascal — SDK DoEvent 
Procedure TECFoo.DoEvent(Const AEventID: Integer; Const AData: Pointer; Const ASize: Cardinal);
Var
  LData: String;
  LCode: Integer;
Begin
  Case AEventID Of

    EVT_FOO_DATA:
    Begin
      If Assigned(FOnData) And (ASize > 0) Then
      Begin
         Var LRaw: RawByteString;
         SetString(LRaw, PAnsiChar(AData), ASize);
         LData := UTF8ToString(LRaw);
         Try
            FOnData(Self, LData);
         Except
         End;
      End;
    End;

    EVT_FOO_TERMINATE:
    Begin
      If Assigned(FOnTerminate) Then
      Begin
         If ASize > 0 Then
         Begin
            Var LRaw: RawByteString;
            SetString(LRaw, PAnsiChar(AData), ASize);
            LCode := StrToIntDef(String(LRaw), 0);
         End
         Else
            LCode := 0;
         Try
            FOnTerminate(Self, LCode);
         Except
         End;
      End;
    End;

  Else
    Inherited DoEvent(AEventID, AData, ASize);
  End;
End;

4.2 — Métodos de operação

Pascal — SDK Method 
Function TECFoo.DoSomething(Const AParam: String): Boolean;
Var
  LRet: String;
Begin
  LRet := ec.Invoke(Handle, _EC_FOO_DO, JsonParam('param', AParam));
  Result := ec.ExtractBoolean(LRet);
End;

4.3 — Late binding

Aplique quando eventos podem chegar durante o Invoke de criação — antes de o consumidor atribuir os callbacks.

Pascal — Late Binding 
Procedure TECFoo.SetOnData(Const ACallback: TECOnFooData);
Begin
  FOnData := ACallback;
{ Late binding: if data arrived before the callback was assigned, deliver now
} If Assigned(FOnData) And (Length(FPendingData) > 0) Then
  Begin
     For I := 0 To High(FPendingData) Do
     Try
        FOnData(Self, FPendingData[I]);
     Except
     End;
     SetLength(FPendingData, 0);
  End;
End;

Factory em TECentric

AttachFoo e Foo — pontos de entrada públicos

5.1 — AttachFoo

Pascal — SDK AttachFoo 
Function TECentric.AttachFoo(Const AHandle: Cardinal): IECFoo;
Begin
  Result := Nil;
  If AHandle > 0 Then Begin
     Result := TECFoo.Create(AHandle);
     RegisterObject(AHandle, Result);
  End;
End;

5.2 — Foo simples

Pascal — SDK Factory Simple 
Function TECentric.Foo(Const AParam: String): IECFoo;
Var
  LRet: String;
  LHandle: Cardinal;
Begin
  Result := Nil;
  LRet := Invoke(0, _EC_ROOT_FOO, JsonParam('param', AParam));
  LHandle := ExtractHandle(LRet);
  If LHandle > 0 Then Begin
     Result := TECFoo.Create(LHandle);
     Result.SetHandle(LHandle);
     RegisterObject(LHandle, Result);
  End;
End;

5.3 — Foo com GSDKPending (eventos durante criação)

ℹ️
Nota: Use esta variante quando eventos assíncronos podem chegar durante o Invoke de criação, antes de o handle ser conhecido. O objeto é pré-registrado no mapa pending indexado por ThreadId.
Pascal — SDK Factory Pending 
Function TECentric.Foo(Const AParam: String): IECFoo;
Var
  LRet: String;
  LHandle: Cardinal;
  LFoo: IECFoo;
  LThreadId: Cardinal;
Begin
  Result := Nil;
  LFoo := TECFoo.Create(0);
  LThreadId := GetCurrentThreadId;
{ Pre-register in pending map so OnCoreEvent can buffer early events
  that arrive during Invoke before the handle is known to the SDK.
} TMonitor.Enter(GSDKLock);
  Try
     GSDKPending.AddOrSetValue(LThreadId, LFoo);
  Finally
     TMonitor.Exit(GSDKLock);
  End;
  Try
     LRet := Invoke(0, _EC_ROOT_FOO, JsonParam('param', AParam));
  Finally
     TMonitor.Enter(GSDKLock);
     Try
        GSDKPending.Remove(LThreadId);
     Finally
        TMonitor.Exit(GSDKLock);
      End;
  End;
  LHandle := ExtractHandle(LRet);
  If LHandle > 0 Then Begin
     LFoo.SetHandle(LHandle);
     RegisterObject(LHandle, LFoo);
     Result := LFoo;
  End;
End;
